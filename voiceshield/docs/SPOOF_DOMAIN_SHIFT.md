# SPOOF_DOMAIN_SHIFT.md — generator diversity, and what it did and did not fix

## Where this started

v1 fixed bonafide-domain robustness and broke spoof generalisation:

| | v0 | v1 |
|---|---|---|
| C unseen bonafide | 0.890 | **0.956** |
| B unseen spoof | **0.956** | 0.799 |

v1 learned "an unfamiliar recording domain is not evidence of synthesis", which correctly
rescues genuine speech and simultaneously excuses unfamiliar *spoofs*. v2 tests whether
spoof-generator diversity repairs that without giving up v1's gain.

## Literature

The evidence is unusually direct, and RawNet2-specific:

> "Training countermeasures with spoofed utterances generated by multiple, differently
> configured attack algorithms is beneficial in terms of generalization... the same
> approach is beneficial for **RawNet2**, with pooled error rates substantially lower
> when training with multiple attack types." (arXiv 2309.09586)

and diversity beats volume — SpeechFake generalises better than a larger corpus purely
because it covers 30 generation methods rather than 10 (arXiv 2606.08038).

## Dataset audit — most of the candidate was unusable

`satwc-reddy/indian-language-deepfake-speech` (CC-BY-4.0) advertises MMS-TTS, SIGVC and
RVC. Verified against the Hub:

| advertised | reality | verdict |
|---|---|---|
| RVC, 701 clips | **0 files exist**; 825 metadata rows reference nothing | **rejected** |
| SIGVC, 16,764 clips | filenames `_ps+4`, `_ps-4`, `_ts0.85` — pitch/time-shifted **real OpenSLR** speech labelled fake | **rejected** |
| "Real speech: OpenSLR" | every one of 22,731 rows is `label=1`; there is no real speech | n/a |
| MMS-TTS, 5,266 clips | genuine Meta MMS neural TTS, native 16 kHz | **used** |

SIGVC was disqualifying on two counts. Pitch-shifting a genuine recording does not make
it a deepfake — training on that teaches the model to flag resampled human speech as
synthetic, the exact false-accusation failure this work has been removing. And all 16,764
filenames match the OpenSLR speaker pattern, while OpenSLR is v1's bonafide Real_B, so
including it would place identical speakers under both labels.

**IndicSynth was also rejected for training** — not on its CC-BY-NC licence but on
methodology: it is the external spoof test set, so training on it would invalidate cells
B and D. The same reasoning kept FLEURS out of training.

Net: v2 gains **one** new generator family, not three.

## Design

    v1  Real_A/2 + Real_B/2 + Fake_A
    v2  Real_A/2 + Real_B/2 + Fake_A/2 + MMS-TTS/2      (treated languages only)

Replacement, not addition, so counts and class balance are identical across v0/v1/v2 and
the only difference from v1 is which generators produced the spoof half. Hindi and
English receive neither Real_B nor MMS-TTS and act as controls on both axes. MMS train/dev
is clip-disjoint by filename hash; no MMS clip enters test.

## Results

| cell | v0 EER / AUC | v1 EER / AUC | v2 EER / AUC |
|---|---|---|---|
| A internal × internal | 1.18 % / 0.999 | 1.68 % / 0.998 | 2.77 % / 0.996 |
| B internal × **unseen spoof** | 8.88 % / 0.956 | 26.14 % / 0.799 | 27.36 % / 0.799 |
| C **unseen bonafide** × internal | 17.52 % / 0.890 | 10.61 % / 0.956 | 11.11 % / 0.960 |
| D **unseen × unseen** | 52.62 % / 0.453 | 49.75 % / 0.478 | 40.12 % / 0.622 |

### Isolating each intervention

| cell | ΔAUC from bonafide diversity (v1−v0) | ΔAUC from generator diversity (v2−v1) |
|---|---:|---:|
| A internal × internal | -0.000 | -0.002 |
| B internal × **unseen spoof** | -0.157 | +0.000 |
| C **unseen bonafide** × internal | +0.066 | +0.004 |
| D **unseen × unseen** | +0.025 | +0.144 |

The isolation is clean: **generator diversity moved cell D and nothing else** — +0.144 AUC
and −9.62 pp EER on the hardest cell, with A, B and C untouched to within ±0.004.

### Per generator (Step 9) — both held out of every training run

| model | freevc24 (VC) | xtts_v2 (TTS) |
|---|---:|---:|
| v0 | 0.356 | 0.550 |
| v1 | 0.377 | 0.578 |
| **v2** | **0.580** | **0.664** |

Adding a single *TTS* family improved detection of an unseen TTS **and** an unseen voice
conversion, and lifted freevc24 from below chance (0.356) to above it. That is genuine
cross-generator transfer, and it is what the literature predicted.

## Safety — v2 gives back everything v1 won

| condition (all GENUINE speech) | v0 | v1 | v2 |
|---|---:|---:|---:|
| clean speech | 0.0 % | 0.0 % | 0.0 % |
| 25% leading silence | 0.0 % | 0.0 % | 0.0 % |
| 50% leading silence | 3.3 % | 0.0 % | 1.7 % |
| 75% leading silence | 36.7 % | 0.0 % | 60.0 % |
| 50% trailing silence | 45.0 % | 20.0 % | 63.3 % |
| internal pause 30% | 15.0 % | 6.7 % | 46.7 % |
| turn-taking gaps | 21.7 % | 6.7 % | 18.3 % |
| low-energy speech (-30 dB) | 0.0 % | 0.0 % | 0.0 % |
| digital silence | 0.0 % | 0.0 % | 100.0 % |
| white noise | 0.0 % | 30.0 % | 0.0 % |
| 50 Hz hum | 100.0 % | 0.0 % | 100.0 % |

v1 eliminated the 50 Hz mains-hum false accusation (100 % → 0 %) and halved trailing-silence
errors. **v2 loses both**: hum returns to 100 %, and trailing silence (63.3 %) and internal
pauses (46.7 %) are worse than v0. Clean speech remains at 0 % for all three.

## Verdict — v2 is NOT frozen

Against the Step 16 criteria:

| criterion | result |
|---|---|
| B improves substantially | **no** — 0.799, unchanged from v1 |
| D improves substantially | **yes** — 0.453 → 0.622 |
| C remains near v1 | yes — 0.960 |
| A remains acceptable | yes — 0.996 |
| no new genuine-speech false accusations | **no** — safety regressed sharply |

Two criteria fail, so v2 is not frozen. This is Step 17 **Case B**: B remains poor, and
the most likely reason is that generator diversity is insufficient — after the audit we
could add exactly one family, where the cited result rests on many more.

## The honest state: a three-way trade-off, no dominant model

| | best at | worst at |
|---|---|---|
| **v0** | unseen spoof with in-domain bonafide (B 0.956) | cross-corpus (D 0.453), hum 100 % |
| **v1** | **safety** — hum 0 %, every silence condition improved | unseen spoof (B 0.799) |
| **v2** | **cross-corpus** (D 0.622), both unseen generators | safety worst of the three |

If one had to ship today, **v1** is the defensible choice: false accusations on genuine
speech are the dominant operational risk, and it is the only version that fixes the hum
failure while also improving external bonafide discrimination.

## Limitations

* One added generator family, not three. Case B cannot be ruled out on this evidence.
* B's regression originates in v1's bonafide change and was not repaired by spoof
  diversity; its cause is not yet isolated.
* MMS-TTS has a distinctly lower crest factor (14.15 vs 16.7–17.4). Peak normalisation
  removes gain but not crest, so "compressed dynamics = spoof" remains an available
  shortcut that was not separately tested.
* The v1 control group showed bonafide gains were **not** language-local; the v2 control
  was not separately re-run.
* One seed per configuration.
